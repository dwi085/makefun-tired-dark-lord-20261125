A 100-word villain monologue for make.fun's "The Tired Dark Lord" bounty. A dark lord who has ruled for centuries greets the hero at his door — not with thunder, but with a queue, a pension plan, and candles burning down. The tiredness lives in the deflections, never in a flat announcement.

## Run it

```sh
node main.ts
```

Writes the monologue to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
